# Prisma

Puzzle diário de luz, espelhos e mistura de cores. Tabuleiro 7×7; feixes que se
cruzam seguem misturados. A semente vem da data — o desafio do dia é o mesmo
para todos.

Plano: [`GAME_PLAN.md`](./GAME_PLAN.md). A lógica em `src/puzzle/` é pura e
testável; o render é Three.js 3D.

```bash
npm install && npm run dev
npm test
npm run build
```
