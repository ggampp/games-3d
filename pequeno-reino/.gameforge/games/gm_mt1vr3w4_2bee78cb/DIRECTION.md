# Direction — Pequeno Reino

- Genre: **Builder / sim** (`city-builder`)

- Verb: construir e gerir
- Objective: atingir meta de população / lucro / harmonia
- Fail: falência / colapso (se o gênero tiver)
- Camera: orbit / isometric

- Engine: three
- Systems: grid, economy, placement, sim-tick
- Tracks: A, B, C, I, H
